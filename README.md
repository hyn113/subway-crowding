# 덜붐 — 지하철 혼잡도 모바일 MVP

모바일 원페이지 시제품입니다. `index.html` 하나로 실행되며 프레임워크나 빌드가 필요 없습니다.

## 기능
- 출발역과 도착역 입력 (현재 UI 시연용이며 실제 역 검증/경로 조회는 하지 않음)
- 30분 단위 혼잡도 막대 선택
- 선택한 시간의 1~10호차 혼잡도 표시
- 모바일 우선 반응형 UI

**중요: 현재 모든 혼잡도 수치는 가상 데모 데이터입니다.** 어떤 역을 입력해도 동일한 예시가 나타나며 실제 통계, 실시간 운행정보, 예측값으로 사용하면 안 됩니다.
